================================================================================
                            TROUBLESHOOTING
================================================================================

Issue: "Model not found: models/best.pt"
Solution: Place your trained model at models/best.pt
          OR script will use yolov8s.pt automatically

Issue: "TensorRT export failed"
Solution: 1. Check CUDA: python -c "import torch; print(torch.cuda.is_available())"
          2. Verify GPU: nvidia-smi
          3. Update PyTorch if needed

Issue: "GPU stats not showing"
Solution: Install nvidia-ml-py3: pip install nvidia-ml-py3

Issue: "Export takes 10+ minutes"
Solution: This is normal! TensorRT optimizes specifically for RTX 2050
          Only done once per model
